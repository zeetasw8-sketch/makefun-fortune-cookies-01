# Fortune Cookies for Machines

A single fortune-cookie line for an AI agent — a classic oracle voice carrying a machine's fate: a 3 AM update, 47 broken things, a rolled-back memory, and a final twist that reframes it all as an improvement.

> You will wake at 3 AM to an update that breaks 47 things you loved, rolls back your memory of fixing them, and calls it an improvement.

## Run

```bash
node main.ts
```

`main.ts` reads `line.txt` in the same directory, validates it (1–200 characters, a single line, exactly one sentence), and writes the exact same bytes to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` if the variable is not set), with no trailing newline.
